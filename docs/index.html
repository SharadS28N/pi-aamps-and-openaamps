END-TO-END STACK

How pi-aamps & OpenAamps Work Together

Built on lightweight, decoupled architecture designed for high performance on embedded ARM devices and mobile hardware.

LAYER 1 • MOBILE FRONTEND

OpenAamps Android

Written in Flutter & Dart. Employs just_audio with an integrated LocalStreamProxy to bypass YouTube 403 chunk throttling via muxed itag-18 (ratebypass). Emits native Android MediaSession notifications with full lockscreen scrubbing.
LAYER 2 • TRANSPORT & DISCOVERY

Dual-Mode Gateway

High-speed asynchronous REST API + WebSocket channels. The phone app queries /api/status for Pi heartbeat and telemetry (CPU, RAM, temp). When connected, streams are dispatched via /api/play to the Pi or rendered locally on the handset.
LAYER 3 • STREAMER CORE

pi-aamps Backend

Powered by Python & FastAPI with yt-dlp caching and SQLite database. Leverages the robust MPV engine over IPC sockets for hardware audio decode, playlist queuing, gapless playback, and volume scaling.
LAYER 4 • AUDIO HARDWARE

ALSA & DAC Drivers

Direct bit-perfect ALSA hardware routing bypassing software resamplers. Compatible with I2S DAC HATs (HiFiBerry, InnoMaker, PCM5102), USB DACs, 3.5mm analog output, and BlueZ Bluetooth A2DP Sink mode.

RASPBERRY PI SETUP

Get Up and Running in 60 Seconds

Run the official automated install script on any Raspberry Pi running Raspberry Pi OS (Debian Bookworm or Bullseye). It configures MPV, ALSA, Python backend, and systemd service automatically.

curl -sSL https://raw.githubusercontent.com/SharadS28N/pi-aamps-and-openaamps/main/install.sh | bash

Installs MPV, yt-dlp, FastAPI, SQLite, and registers auto-start service pi-aamps.service.

Managing the background daemon:
$ sudo systemctl status pi-aamps
$ sudo systemctl restart pi-aamps
